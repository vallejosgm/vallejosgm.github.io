iOS CASE STUDY

CeciStyle iOS Admin

A native iOS administration application built for a real business workflow, giving authorized users mobile access to customer appointments and day-to-day operational tools.

Swift · SwiftUI · REST APIs · Keychain · Face ID · Firebase Cloud Messaging

View GitHub RepositoryBack to Portfolio

Overview

CeciStyle iOS Admin provides mobile appointment management for CeciStyle. The application communicates with the business backend through REST APIs and allows authorized users to review and manage appointments directly from an iOS device.

The project was developed in Swift using SwiftUI and integrates authentication, biometric access, Firebase Cloud Messaging, backend services, and secure credential storage.

The Business Problem

Administrative work should not always require staff to be at a desktop computer. Appointment information can need attention while moving through day-to-day business operations. The iOS client provides a focused mobile interface to the existing backend rather than duplicating business data in a separate system.

What I Built

Appointment Management

Authorized users can view appointments organized by date and create, edit, or delete appointment records.

REST API Integration

The application communicates with the existing business backend and retrieves appointment and service information through REST APIs.

Secure Authentication

Bearer-token authentication is combined with secure token storage using iOS Keychain Services.

Biometric Access

LocalAuthentication supports Face ID and biometric authentication for convenient protected access.

Push Notifications

Firebase Cloud Messaging and UserNotifications support notifications and badge management for new appointments.

Mobile Data Refresh

Users can manually refresh appointment information so the administrative interface can retrieve current backend data.

Engineering Highlights

Keychain Token Storage

Authentication tokens are stored using iOS Keychain Services instead of UserDefaults, keeping authentication material in the platform's secure credential storage.

Biometric Authentication

The application integrates LocalAuthentication to provide Face ID and biometric access as part of the administrative experience.

Backend Integration

The mobile application acts as a client of the existing business backend, using JSON/Codable models and REST API communication rather than creating an isolated mobile data source.

Configuration Hygiene

Environment-specific configuration and Firebase configuration are excluded from version control, while an example configuration documents the expected local setup without exposing production credentials.

Testing

The project includes unit tests for the Appointment model covering JSON decoding, optional values, and equality behavior. Additional UI test targets are also included in the Xcode project.

Technology

Swift · SwiftUI · Foundation · LocalAuthentication · UserNotifications · Firebase Cloud Messaging · REST APIs · JSON / Codable · iOS Keychain Services · CocoaPods

What This Project Demonstrates

This project demonstrates native iOS development connected to a real business system: mobile UI development, REST API integration, authentication, secure credential storage, biometric access, notifications, data modeling, configuration management, and testing.

The repository contains the iOS administration client. Backend services and production credentials are intentionally not included.
